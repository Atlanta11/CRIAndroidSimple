# CRIAndroidSimple

Simple Android Studio CRI client layout:
- Connect / Disconnect
- Connection information
- Send / Load / Start / Stop / Pause program
- Log

TCP default port: 3920.
Open the folder in Android Studio and let Gradle sync.
